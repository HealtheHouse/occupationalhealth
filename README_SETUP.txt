راهنمای نسخه گردش پرونده چندسطحی سامانه

1) فایل SUPABASE_SETUP.sql را در Supabase > SQL Editor اجرا کنید.
2) فایل‌ها را روی GitHub Pages یا هاست خود قرار دهید.
3) از صفحه اصلی وارد «فرم بازرسی بهداشت حرفه‌ای» شوید.
4) در یک پرونده می‌توانید چند شاغل را ثبت کنید:
   - نفر فعلی را تکمیل کنید.
   - «ذخیره نفر فعلی و ثبت نفر بعدی» را بزنید.
   - نفر بعدی را ثبت کنید.
   - همه نفرات زیر همان پرونده و همان لینک ذخیره می‌شوند.
5) «ایجاد لینک اختصاصی / ارسال» فقط یک‌بار برای پرونده لینک می‌سازد.
6) در مراحل بعدی از «ذخیره و به‌روزرسانی همان لینک» استفاده کنید؛ برای هر مرحله لینک جدید ساخته نمی‌شود.
7) گردش پرونده:
   بازرس -> کارشناس بهداشت حرفه‌ای -> پزشک طب کار -> بازرس
   گیرنده مرحله بعد از فهرست «گیرنده» انتخاب می‌شود.
8) وقتی گیرنده لینک را باز می‌کند، سطح فعال پرونده از روی وضعیت سرور تعیین می‌شود و بخش‌های مربوط به همان سطح قابل ویرایش هستند:
   - بازرس: بخش‌های بازرسی و مدیریت نفرات
   - کارشناس بهداشت حرفه‌ای: بخش ارزیابی عوامل زیان‌آور شغلی و نظریه کارشناسی
   - پزشک طب کار: بخش‌های پرونده و معاینات پزشکی (به‌جز بخش تخصصی کارشناس)
9) پزشک یا کارشناس پس از تکمیل، گیرنده بعدی را انتخاب کرده و «ذخیره و به‌روزرسانی همان لینک» را می‌زند. لینک ثابت می‌ماند.
10) حذف پرونده از بخش «حذف پرونده برای همه سطوح» انجام می‌شود و رکورد روی سرور حذف می‌گردد.

نکته امنیتی:
این نسخه گردش نقش‌ها را در رابط کاربری و وضعیت پرونده کنترل می‌کند. برای احراز هویت واقعی و جلوگیری قطعی از دسترسی افراد غیرمجاز، باید Authentication در Supabase نیز فعال شود.
